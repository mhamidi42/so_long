## Description
so_long est un projet graphique du cursus 42 consistant à développer un petit jeu 2D en C.

Le joueur doit collecter tous les objets présents sur la carte puis atteindre la sortie en se déplaçant dans le niveau.

## Objectif
Ce projet permet d'apprendre à :
- utiliser une bibliothèque graphique (MiniLibX)
- gérer une fenêtre et les événements clavier
- afficher des textures et des sprites
- parser une carte et vérifier sa validité
- implémenter une logique de jeu simple

## Technologies
- C
- MiniLibX
- Gestion d'événements
- Makefile
- Linux

## Compilation
make

## Utilisation
./so_long map.ber
